# CRUNCHER

A first-person horror game in a single HTML file. No build, no dependencies — open `index.html` in a browser (headphones on).

Find 5 fuses in the abandoned Cruncher Cereal plant, power the exit door, and escape. Cruncher hunts by sound and light.

- **WASD / arrows** move, **mouse** look, **Shift** run, **F** flashlight
- Running is loud, the flashlight is a beacon; darkness hides you
- The maze is regenerated every run
